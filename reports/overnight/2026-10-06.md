## Code Review — Shortcomings & Issues

Ponytail lens: redundancy, over-engineering, reinvented stdlib first.

1. **Both live embed scripts' docstrings name deleted files** — embed_peptides_esmc.py:21,24,27,30 instruct `python src/tools/esm/embed_peptides_w_esm.py ...` (deleted in fe62ea7); embed_peptides_esmif.py:3,41,42 name `embed_windows_esmif.py` (deleted in a33e7b6; the deferral is recorded in db04c28's commit message but never carried out). The SLURM path itself is fixed, so this is documentation-only drift — but usage instructions now point at files that do not exist, the same doc/code drift class the indexing audit exists to catch. Severity: maintainability. Commits a35b00e, fe62ea7, a33e7b6, db04c28 (fix never applied). This is the residual half of the previous report's finding 1.

2. **Dead code commented, not deleted, in two places** — fetch_structures.sh:43-59 is a nested while-loop reading from /dev/null that parses nothing (the real parser is the awk block at :60-76); commit 92326d2 added a comment explaining it is unused instead of removing the ~17 lines. embed_peptides_esmif.py:457 allocates `ZERO_WINDOW` and marks it `# unused` instead of deleting the line (2ec0c00). Deletion over addition; the comment is more code than the removal. Severity: maintainability (low). Commits 92326d2, 2ec0c00.

3. **Speculative importability via module-level mutable globals** — embed_peptides_esmif.py:77-81 declares `args = None; DEVICE, USE_GPU = "cpu", False; model = alphabet = None`, mutated by main() through a `global` statement (:387), so helpers (get_encoder_output_gpu :85-97, encode_structure :100, probe_constants :123) read hidden module state. The stated purpose ("helpers stay importable", :77-78) is unused: `git grep` finds no module that imports embed_peptides_esmif.py at tip. The __main__ guard itself is good; the globals pattern is the avoidable cost — passing the few needed values, or keeping the script shape, is smaller. Severity: maintainability (over-engineering). Commit 9572514.

4. **Comment churn and mismatched commit subjects** — 2ec0c00 and 92326d2 add restating trailing comments (`# `, `# w`, `# Check if the padded FASTA file exists`, `# SAVE CORRECT FASTA LENGTH`) and restyle existing section headers in place (`# ── X ──` → `# X ` in fetch_structures.sh; → `###### X` in prepare_fetch_list.sh) with zero behaviour change. 669afb2's subject "Move report_structure_coverage.py to src/investigation/" describes a move completed in the immediately preceding commit 4cf5543; its diff is fetch_uniprot_fastas.py comments. Severity: style (low). Commits 2ec0c00, 669afb2, 92326d2.
