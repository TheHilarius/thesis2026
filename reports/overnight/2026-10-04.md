## Code Review — Shortcomings & Issues

Ponytail lens: over-engineering, redundant code, and reinvented stdlib first.

1. **Embed-script "rename" left a full duplicate and stale entry points** — `src/tools/esm/embed_peptides_esmc.py` vs `embed_peptides_w_esm.py` differ by 36 lines of ~600 (diff of HEAD blobs); the commit message says "Renaming" but no file was deleted. Worse, the repo's real entry points still run the OLD script: `run_esmc_embeddings.sh:37`, `src/README.md:29`, and the new file's own usage docstring (`embed_peptides_esmc.py:23,26,29,32` all name `embed_peptides_w_esm.py`). So the convention-hardening (asserted `1idx_inclusive`, `:55`) is inert on the actual pipeline path while a convention-DRIFTING auto-detecting variant stays live — the exact failure mode the audit exists to catch. This is the third instance of the duplicate-script pattern this report series has flagged (cf. the 09/10 padded-subset scripts). Severity: maintainability (risk on data drift). Commit 26ec48d.
2. **Run-set README records generation time as provenance and asserts measured-zero runtime** — `runs/winmat_flat_20260928_164804/README.md:3` says "Started: 2026-10-02 15:13:01" while the folder name and its own line 7 say the campaign ran 20260928_183006..20261001; line 8 says "total runtime: 0.0s" and every row's `runtime_s` is "?" — yet the tracked logs carry real runtimes (16254.7 s in the example above). Root cause is in the generator, not the data: `04b_run_matrix.py:340` passes `datetime.now()` as "Started" although `stamps[0]` (already computed at `:317-318`) is the first run timestamp; `:329` prints `total runtime: {total_rt:.1f}s` which becomes a hard 0.0 when JSONs lack `runtime_seconds` (mapped to "?" at `:239`). Regeneration clobbers provenance — 9d981d8 is exactly that clobber (14:38:54 → 15:13:01). Two call sites also write different schemas to the same `README.md` (aggregate path `:401-414` vs `--write-readme-only` `:342-352`), so the flag rewrites whatever the run path produced. Lazy fix: one line for `Started`, omit the runtime line when absent. Severity: maintainability (thesis documentation cites these folders). Commits 04a5623, 9d981d8.
3. **README "aggregate tables" attribution is unchecked** — the generator lists any `results/model_matrix_*.tsv` in the folder (`04b_run_matrix.py:322`) without checking coverage, so the winmat README presents pre-campaign aggregates (20260926–28, see Results) as the campaign's tables; the three files also overlap each other by 13 rows. Severity: risk (mis-cited results). Commits 506474c, 04a5623.
4. **`.gitignore` pattern duplicated** — `runs/*/models/` with an identical comment exists at `.gitignore:121` (from 0d4cf9f) and `:124` (re-added by 30f34e0, whose diff shows the copy-paste). Severity: style. Commit 30f34e0.
